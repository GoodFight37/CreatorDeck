Manifeste des 50 entrées

Pour consulter les résultats détaillés de l'audit, veuillez examiner le fichier manifeste.csv.

Ce fichier contient pour chacune des 50 pistes : - Le slug et le nom - Les URLs source (quand disponibles) - Les dimensions de l'image (quando disponibles) - Le crédit auteur et les droits observés - Le statut d'adéquation (aucune source adéquate, droits à vérifier, utilisable selon conditions vérifiées, organisation) - Une justification factuelle basée sur les critères de recherche - Le nom de fichier associé (quando disponible)

Rappel important concernant les droits d'utilisation :

  • Le statut « utilisable selon conditions vérifiées » signifie que l'image peut être utilisée si les conditions de licence sont respectées (attribution, partage identique, etc.)
  • Le statut « droits à vérifier » signifie que bien que l'image soit téléchargeable, les droits d'utilisation spécifiques à cette application doivent être confirmés auprès du détenteur des droits
  • Aucune image n'est déclarée comme approuvée pour publication dans cet audit
  • Toutes les utilisations potentielles nécessitent une vérification préalable des droits conformément aux lois applicables
